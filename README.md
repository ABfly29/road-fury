# Road Fury

Road Rash–style pseudo-3D motorbike racer on HTML5 Canvas (Vite + TypeScript).

**Live:** https://abfly29.github.io/road-fury/

## Develop
```
npm ci
npm run dev
npm run build && npm run preview   # served at /road-fury/
```
Node 24 (see `.nvmrc`). Pushes to `main` deploy to GitHub Pages via `.github/workflows/deploy.yml`.
